# Исходное техническое задание

1. Определение режима сети - бс, чс, авто (фарватер)
2. Пинг всех серверов (keqdroid) и отсекание только работоспособных (фарватер)
3. Автовыбор сервера среди всех подписокс учётом текущего состояния и истории задержек, разбросов и отказов, периодически проверка работоспособности выбранного сервера (как в Keqdroid)
4. замена сервера при заметно лучшем варианте, порог улучшения и минимальное время между переключениями;
5. Возможность скрыть нерабочие серверы из общего списка
6. объединение серверов из всех подписок в группы - по планируемому/определённому режиму сети, стране точки выхода, тегу/ключевым словам (пресет+кастом)
7. Создание цепочек серверов - как сервер-сервер, так и группа серверов - группа серверов (например, доступ к легальным сайтам в ru зоне во время работы белых списков)
8. Продвинутая маршрутизации
- выбор сервера исходя из условий - правила как в keqdroid + режим сети + возможность выбор не только конкретного сервера, но и цепочки из серверов/групп серверов/точке выхода, 
- больше пресетов маршрутизации, 
- подключение кастомного автообновляемого hosts (например от steven black), 
- просмотр, редактирование и отключение правил провайдеров подписки
- обращения к интерфесу TUN из рабочего профиля автоматически отбрасываются по UID
9. Интеграция Tailscale для доступа к своему Tailnet с поддержкой обфускации через AmnesiaWG 1.5+, а также реализацией остальных функций оригинального приложения
10. Закрытие максимума уязвимостей по документации https://github.com/xtclovver/RKNHardering

## Дополнения пользователя в чате

1. Основной репозиторий разработки и версий: https://github.com/orrtyom/orrdroid.
2. Автоматическая синхронизация настроек и подписок между телефоном, планшетом, компьютером, ТВ и другими телефонами.
3. Одно устройство в группе — главное; ведомые не могут переписать его настройки.
4. Предпочтительный рассматриваемый транспорт синхронизации — Tailnet.
5. Поддержка AmnesiaWG уже есть в Keqdroid: переиспользовать её, не планировать создание с нуля.
6. Оценить готовый форк Tailscale с AWG: https://github.com/LiuTangLei/tailscale-awg-installer (реальное ядро и мобильная обвязка вынесены в связанные репозитории).
7. Учесть существующий вход в Tailscale через Auth key в Karing.

Уточнённая интерпретация требований и ограничения находятся в PLAN.md и SYNC.md. Исходное ТЗ выше сохранено без смысловой правки.
