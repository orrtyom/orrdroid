# Orrdroid

Проект Android-клиента на основе [Keqdroid](https://github.com/Lemonochka/keqdroid) с условными маршрутами БС/ЧС, общим автовыбором серверов из нескольких подписок и проверкой фактической передачи данных.

**Сейчас идёт проектирование.** В репозитории находятся требования, исследования и план. Исходники Keqdroid ещё не импортированы, сборок Orrdroid нет. Ниже перечислены планируемые функции.

Основная цель — сохранять доступ к нужным сервисам при смене сети и ограничений, соблюдая маршруты и ручной выбор пользователя.

**БС** — сеть с белыми списками, где напрямую доступны только разрешённые назначения. **ЧС** — сеть с выборочными блокировками и замедлениями, где остальные назначения доступны напрямую. Это режимы сети; списки адресов и подписки серверов настраиваются отдельно.

## Первый этап

| Направление | План |
|---|---|
| Маршруты | «Кто → Что → Когда → Куда», новый список «Заблокировано для РФ», условия «Всегда / БС / ЧС» |
| Режим сети | Ручное БС/ЧС и полный перенос сценария первого запуска и определения режима из Farvater с интеграцией в Keqdroid |
| Цепочки | Явный выбор сохранённой статической цепочки в «Куда» через mihomo |
| Шаблоны | Согласованные правила БС/ЧС, которые пользователь применяет и настраивает сам |
| GlobalAuto | Все разрешённые подписки, исключения, резерв, ограничения провайдеров, сохранение ручного выбора |
| Проверки | Сохранение своего HTTPS URL, проверка тела и передачи с лимитами времени/объёма |
| Список серверов | Опциональное скрытие не прошедших проверку, отдельные состояния непроверенных и устаревших |
| LAN | Обязательные логин/пароль SOCKS5/HTTP, полная ссылка и QR |
| Совместимость | Миграция backup, сохранение маршрутов, согласование восстановления VPN с режимами |

Существующие возможности Keqdroid переиспользуются — пакетные проверки серверов/подписок/цепочек, DIRECT/BLOCK/текущий/отдельный сервер, статические цепочки, hosts/AdBlock/списки по URL, AmnesiaWG через mihomo, резервное копирование и восстановление сохранённой VPN-сессии.

После чистой установки сохраняется штатная цель проверки Keqdis/Keqdroid. Пользователь сам добавляет нужные правила и при необходимости задаёт свой HTTPS URL.

Если ни одно правило не совпало, в ЧС трафик идёт напрямую, в БС — через текущий сервер. Совпавшее правило с обязательным выходом при его недоступности использует только явно разрешённый резерв либо блокировку. Страна выхода определяется по фактическому пути, для цепочки — по последней ступени.

Полный состав, относительная сложность, порядок реализации и критерии готовности закреплены в [плане первого этапа](docs/orrdroid/PLAN.md#2а-утверждённый-первый-этап).

## Проверенная база

На 12 ноября 2026 проверены **Keqdroid v0.36.3**, **Karing v1.2.26.2929** и **Farvater v1.0.31**. Для импорта Keqdroid выбран commit `7a334bcd040e36e8506970958659990b1cc260c1`. Перед началом реализации новые изменения upstream проходят отдельную проверку.

[Сравнение возможностей и ссылки на исходники](docs/orrdroid/CURRENT_CAPABILITIES_2026-11-12.md) содержит границы проверки. Полевые испытания и преимущество Orrdroid в стабильности пока не подтверждены.

## Происхождение проекта

Основная кодовая база для будущего форка — [Keqdroid / Lemonochka](https://github.com/Lemonochka/keqdroid). [Farvater](https://github.com/farvater-app/farvater) служит источником сценария запуска и определения режима. [Karing](https://github.com/KaringX/karing) используется как пример групп автовыбора и маршрутизации.

Orrdroid — самостоятельный проект. При импорте и переносе кода сохраняются история, авторство и применимые лицензии исходных проектов. Статус функций и версии Orrdroid учитываются отдельно от upstream.
