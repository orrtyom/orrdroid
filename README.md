# Orrdroid

Проект на основе [Keqdroid](https://github.com/Lemonochka/keqdroid), ориентированный на стабильность подключения, автоматический выбор узлов из нескольких подписок и управляемую маршрутизацию.

**Статус: проектирование.** Здесь зафиксированы требования и план; исходный код Keqdroid ещё не импортирован, сборок Orrdroid нет. Наличие пункта в плане не означает, что функция реализована.

Проверенная исходная база: Keqdroid **v0.36.1**, commit `eca4c926f096731fec3f6746c15625c53b1c6573`. Перед импортом сверить изменения новых версий и зафиксировать выбранный commit.

Главный показатель качества — время, в течение которого нужные пользователю сервисы действительно работают. Минимальный пинг сам по себе не является целью.

Редакция ТЗ 0.4: синхронизация с защищённым главным устройством либо последних изменений со всех устройств. Каналы — Tailnet, LAN, шифрованный файл и опциональные хранилища. LAN SOCKS5/HTTP требует логин/пароль и поддерживает копирование ссылки/QR. AmnesiaWG уже имеется в Keqdroid через mihomo; новая работа относится к интеграции Tailnet и совместному исполнению, а не к созданию поддержки AWG с нуля.

Дальнейшая разработка ведётся в этом репозитории. Этапы и правила версионирования описаны в плане. Предложение для Keqdroid подготовлено для обсуждения; автору оригинального проекта оно не отправлялось.
